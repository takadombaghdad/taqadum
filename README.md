# تطبيق حزب تقدّم

تطبيق ويب يعمل مثل تطبيق موبايل حقيقي (PWA) — يعرض أخبار الحزب، ومعه لوحة تحكم بسيطة لإضافة/تعديل/حذف الأخبار مباشرة من الهاتف، بدون حاجة لمتجر تطبيقات.

## كيف تشغّله وتنشره

يحتاج التطبيق إلى استضافة عبر **رابط HTTPS** (شرط أساسي لعمل PWA وتثبيته). أسهل الطرق:

1. **GitHub Pages** (مجاني): أنشئ مستودع، ارفع هذه الملفات، فعّل GitHub Pages من إعدادات المستودع.
2. **Netlify / Vercel** (مجاني): اسحب مجلد المشروع وأسقطه في لوحتهم، وتحصل على رابط جاهز فوراً.
3. أي استضافة عادية (سيرفر الحزب، إلخ) — فقط ضع الملفات كما هي.

## كيف يثبّته الزائر على هاتفه

- **آيفون (Safari):** فتح الرابط ← زر المشاركة (Share) ← "إضافة إلى الشاشة الرئيسية".
- **أندرويد (Chrome):** فتح الرابط ← تظهر رسالة "تثبيت التطبيق" تلقائياً، أو من القائمة ⋮ ← "تثبيت التطبيق".

بعد التثبيت يظهر التطبيق بأيقونته الخاصة على الشاشة الرئيسية ويعمل كأي تطبيق عادي (بدون شريط المتصفح).

## لوحة التحكم

- من تبويب "لوحة التحكم" داخل التطبيق.
- تسجيل الدخول الحالي: اسم المستخدم `takadom` — كلمة المرور `Mm664482mm@@`
- **الحماية:** كلمة المرور غير مخزّنة كنص واضح بالكود — مخزّنة كهاش تشفيري (SHA-256) بثابت `CREDENTIALS_HASH` بملف `app.js`. لتغيير الاسم أو كلمة المرور مستقبلاً، يلزم حساب هاش جديد (لا يكفي تعديل نص بسيط بالكود).
- الأخبار تُحفظ حالياً على متصفح كل زائر (localStorage) — أي خبر تضيفه من جهازك يظهر لك فقط، وليس لكل الزوّار. هذا مناسب للتجربة والعرض، لكن **للنشر الفعلي** حيث يرى كل الزوار نفس الأخبار، يلزم ربط التطبيق بقاعدة بيانات مركزية (خطوة توسّع لاحقة، راجع القسم التالي).

## التوسيع والتعديل لاحقاً

بنية الملفات مقسّمة بشكل مقصود لسهولة التعديل:

| الملف | المسؤولية |
|---|---|
| `index.html` | الهيكل العام والتبويبات |
| `style.css` | كل الألوان والتصميم (اللون الأساسي معرّف في متغيّر `--accent`) |
| `app.js` | كل منطق الأخبار ولوحة التحكم |
| `manifest.json` | اسم التطبيق وأيقونته وألوانه كتطبيق مثبّت |

أهم نقاط التوسّع الشائعة:

- **ربط قاعدة بيانات حقيقية** (بحيث تظهر الأخبار لكل الزوار): استبدل الدالتين `loadNews()` و `saveNews()` في `app.js` بنداءات إلى API خاص بكم (مثل Firebase أو أي خادم بسيط).
- **تغيير الألوان أو الشعار:** كل الألوان في أول ملف `style.css` ضمن `:root`، والأيقونة في `icon.svg`.
- **إضافة أقسام جديدة** (فعاليات، عضوية، تواصل): كرّر نفس نمط التبويبات الموجود في `index.html` و `app.js`.
